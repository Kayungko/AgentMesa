# AgentMesa Claude Plugin

Claude Code plugin skeleton for AgentMesa.

Planned capabilities:

- Mesa MCP configuration.
- AgentMesa skill for handoff and review loops.
- Commands:
  - `/agentmesa:meet`
  - `/agentmesa:handoff`
  - `/agentmesa:read-review`
  - `/agentmesa:fix-from-review`
- Hooks for post-implementation handoff.
