# CLAUDE.md

This project uses AgentMesa for structured AI agent handoffs.

## Builder Rules

When you complete an implementation:

1. Update the AgentMesa task status to `ready_for_review`.
2. Write an implementation summary.
3. Attach changed files and relevant git diff context.
4. Request Codex or another reviewer through AgentMesa.
5. Wait for review result before marking the task complete.

## Fix Rules

When a review requests changes:

1. Read the review report.
2. Fix each issue or explain why it should not be changed.
3. Write a fix summary.
4. Request another review.
